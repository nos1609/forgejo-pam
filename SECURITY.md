# Политика безопасности

English summary is provided below.

## Поддерживаемая область

Проект принимает сообщения об уязвимостях в упаковочной дельте, COPR-обвязке,
RPM scriptlets, systemd capabilities, SELinux policy и управлении ACL. Ошибки в
самом Forgejo сначала сверяйте с upstream Forgejo.

## Закрытое сообщение

Используйте **Report a vulnerability** в разделе GitHub Security Advisory этого
репозитория. Не публикуйте рабочий exploit, учётные данные, конфигурацию сервера
или персональные данные в GitHub Issue.

Укажите затронутый commit или NVR, платформу, ожидаемое и фактическое поведение,
минимальные шаги воспроизведения и влияние. Удалите секреты и адреса рабочих
узлов из журналов.

Публичный срок исправления заранее не гарантируется. Проект подтвердит область
ошибки, согласует раскрытие и укажет проверяемый выпуск, когда исправление будет
готово.

## English summary

Report vulnerabilities in the packaging delta through this repository's
private GitHub Security Advisory form. Do not publish working exploits,
credentials, server configuration, or personal data in a public issue. Include
the affected commit or NVR, platform, minimal reproduction, and impact.
